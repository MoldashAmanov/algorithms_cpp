=== Суть ===
Не сравнивает числа напрямую. Сортирует их порязрядно (начиная с младшего или
старшего разряда), используя стабильную сортировку как вспомогательную.

=== Сложность ===
Время: O(d * (n + b)), где d - количество разрядов, b - основание.

=== Память ===
O(n + b)

# Разбор countingSortByDigit:
# exp - текущий разряд (1 для единиц, 10 для десятков, 100 для сотен и тд)
# (arr[i] / exp) % 10 - извлекает цифру в разряде exp. Например, для
arr[i]=345, exp=10: 345/10=34, 34%10=4 (цифра десятков)
# Первый цикл: считаем, сколько раз встречается каждая цифра 0-9
# Второй цикл: превращаем count в массив префиксных сумм = теперь count[d] 
хранит позицию, куда должен встать последний элемент с цифрой d
# Третий цикл (с конца!): проходим исходный массив справа налево. Это критично для
стабильности - равные по текущему разряду элементы сохранят свой относительный порядок
# output[count[...] - 1] = arr[i] - кладем элемент на его место
# count[...]-- - уменьшаем счетчик, чтобы следующий элемент с той же цифрой встал левее
