=== Суть ===
Массив рекурсивно делится пополам до массивов из 1 элемента, 
затем отсортированные части сливаются воедино. Гарантирует стабильную
сложность.

=== Сложность ===
Время: О(n log n), Память: О(n)

# Разбираем merge:
# temp * временный массив размера right - left + 1, куда будем складывать
результат слияния.
# i * указатель на начало левой половины [left, mid].
# j * на начало правой [mid + 1, right].
# Первый while * пока в обеих половинах есть элементы, сравниваем
arr[i] и arr[j], меньший кладем в temp и сдвигаем соответствующий указатель.
Условие <= обеспечиваем стабильность сортировки.
# Второй и третий while * одна из половин закончилась раньше - дописываем
остатки другой.
# Последний цикл * копируем temp обратно в arr на позиции [left, right].
# Разбор mergeSort:
# if (left >= right) return * массив из 0 и 1 элемента уже отсортирован.
# Делим пополам, рекурсивно сортируем каждую половину, затем сливаем
их через merge.
