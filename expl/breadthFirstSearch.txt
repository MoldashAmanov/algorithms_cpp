Поиск в ширину (BFS - Breadth-First Search)

=== Суть ===
Обход графа "в глубину" по уровням. Используем очередь (Queue). Идеален
для поиска кратчайшего пути в невзвешенном графе

=== Сложность ===
Время: O(V + E)
Память: O(V)

# Пошаговый разбор
# visited - массив флагов, чтобы не посещать вершину дважды
(иначе цикл в графе приведет к бесконечному циклу)
# queue<int> q - очередь хранит вершины, которые нужно обработать.
Очередь обеспечивает порядок "сначала ближайшие"
# visited[start] = true; q.push(start) - помечаем стартовую вершину
и кладем в очередь. Важно: помечаем сразу при добавлении в очередь, а не
при извлечении. Это предотвращает дубликаты в очереди
# while (!q.empty()) - пока есть вершины для обработки
# curr = q.front(); q.pop() - достаем текущую вершину
# for (int neighbor : ajd[curr]) - перебираем всех соседей
# if (!visited[neighbor]) - если сосед еще не посещен, помечаем и кладем
в очередь
